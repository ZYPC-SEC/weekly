## `ssrf`是什么

**服务端请求伪造**，由攻击阵构造请求，由**服务器端**发起请求的安全漏洞。

**形成的原因?** 通常是服务器提供了**从其他服务器获取数据**的窗口,但没有对目标地址进行严格的过滤和限制

例如：
- 允许用户指定url的图片下载功能
- RSS订阅(简易信息聚合),接口回调,在线文档解析等

有两种思路:

## 有回显--直接访问

请求结果被返回到了前端(回显型)

## 无回显外网--DNSLog

没有回显,属于**盲SSRF**.

方法:
1. 使用`dnslog`平台或是自己搭建([dig.pm/](https://link.zhihu.com/?target=https%3A//dig.pm/))
2. 控制url,访问dnslog网址
3. 同时,除了`http`,`https`等协议,还有`gopher`,`dict`,`ftp`等协议可以尝试

## 内网检测

确认ssrf能够访问内网,并进行端口/服务检测

2. 靶场服务器收到后，由**它自己**去解析这个 URL 并建立 TCP 连接。发起连接的进程在靶场机器上，所以对端 socket 的源地址就是 `127.0.0.1`。

4. 白名单通过。

## `kernel namespaces and cgroups`:

内核命名空间及控制组:是linux内核的两大底层机制,是现代容器技术(Docker,Kubernetes)的基石

### `namespace`:资源隔离

作用:让一组进程只能看到之际那部分的系统资源,彼此互不干扰

### `cgroups`:资源限制

作用:统计和限制一组进程所能使用的物理资源上限

- **限制资源** 比如:限制最多一个cpu核心,1gb内存
- **控制优先级** 给不同容器分类配不容的cpu或磁盘I/O权重

## What is a container image?

允许容器时,将会使用一个独立的**文件系统**(filesystem).这个定制文件系统由**文件镜像**提供.由于镜像包含了容器的文件系统,他必须包含所有运行应用程序的所有内容.有:
- `Binaries` **二进制文件**,以及他依赖的可执行工具(如:`/bin/my-app-binary`)
- `Dependencies` **依赖项**,应用运行所需的库文件、系统包或框架。它们通常被打包在独立的“依赖层”中，位于操作系统基础层之上、应用层之下。
- Configuration **配置**,应用的配置文件(如:`/etc/my-app.d/default.cfg`),以及镜像的**元数据**.元数据包含启动命令,环境变量,暴露的端口等,他们记录在镜像的"配置对象"中
- Scripts **脚本**,启动脚本或是初始化脚本.在镜像规范里,通常体现为配置中的**入口命令**(Entrypoint)或**命令**(cmd)
- etc.

如何组织镜像?按照`OCI`(开放容器倡议),一个镜像由两部分组成:
- **文件系统层(Filesystem Layers)**:上述的二进制,依赖,配置文件,脚本等,实际上都是以**层**的形式堆叠存储,每一层都是一个`tar`归档,代表文件的一次**变更集**.操作系统是一层,安装依赖是一层,放入你的应用和配置又是一层
- **配置(Configuration)**:一个JSON文件,记录了如何运行这个镜像

**变更集**? (changeset)指的是**镜像层所代表的那一次文件系统的改动**,一个镜像层就是一个变更集--记录的是相对于上一层,文件系统发生了什么变化

**tar**? 是unix/linux下最经典的**归档**(archive)工具,功能是**将多个文件打包为一个文件**,方便存储和运输.变更集就是以tar归档的形式存储和分发

反序列化就相当于新建了一个类,这个类中会有很多方法

**序列化:将变量转换为可保存或传输的字符串的形式的过程**;实现的函数是`serialize()`
**反序列化:就是将字符串转换为原来的变量使用,即序列化的逆过程**;实现的函数是`unserialize()`
## 序列化的格式

示例如下：
```php
<?php
class example{
protected $string="test";
private $integer=1;
var $null=null;
public $double=1.2;
public $bool=True;
}
echo serialize(new example());
?>
```
运行得到：
```text
O:7:"example":5:{s:9:"*string";s:4:"test";s:16:"exampleinteger";i:1;s:4:"null";N;s:6:"double";d:1.2;s:4:"bool";b:1;}
```
这里的结构就是：
```text
O:length:class name:attribute number:{attr1;value1;attr2;value2;}
```

`O`**代表对象**
`length`**类名的长度**(字节)
`class name`**类名**
`attribute number`**属性数量**
后面大括号内依次是：**属性名**和对应的**值**

例如：`s:9:"*string";s:4:"test";`就是一个**键值对**,`s`表示**字符串**,`"*string"`表示**属性名**,后面接着的是`s`表示**字符串**,长度是`4`个字节,**值**为`text`

注意到所有的属性名都是`s`类型的

其中有三个修饰符:`protected`,`private`和`public`(var?),是**用于控制属性或是方法的可见性(访问控制)的修饰符**,用来控制谁可以访问这个属性或是方法.如下:

| 修饰符         | 谁能访问                  |
| ----------- | --------------------- |
| `public`    | 任何地方（类内部、子类、类外部）都能访问  |
| `protected` | **只有本类和子类**能访问，类外部不能  |
| `private`   | **只有本类**能访问，子类和类外部都不能 |
举例如下(ds):
```php
class A {
    public    $pub = "公开";
    protected $pro = "受保护";
    private   $pri = "私有";

    public function show() {
        echo $this->pub;  // ✅ 本类内可访问
        echo $this->pro;  // ✅ 本类内可访问
        echo $this->pri;  // ✅ 本类内可访问
    }
}

class B extends A {
    public function showB() {
        echo $this->pub;  // ✅ 子类可访问 public
        echo $this->pro;  // ✅ 子类可访问 protected
        echo $this->pri;  // ❌ 子类不能访问 private
    }
}

$a = new A();
echo $a->pub;  // ✅ 类外部可访问 public
echo $a->pro;  // ❌ 类外部不能访问 protected
echo $a->pri;  // ❌ 类外部不能访问 private
```

在 PHP 序列化格式里，每个值开头用一个小写字母表示它的**类型**：

| 标记  | 类型                          | 示例                |
| --- | --------------------------- | ----------------- |
| `N` | NULL                        | `N;`              |
| `b` | boolean（布尔）                 | `b:1;`            |
| `i` | integer（整数）                 | `i:42;`           |
| `d` | double（浮点数）                 | `d:1.5;`          |
| `s` | **string（字符串）**             | `s:4:"test";`     |
| `a` | array（数组）                   | `a:2:{...}`       |
| `O` | object（对象）                  | `O:1:"N":2:{...}` |
| `R` | 指针引用（reference）             | `R:2;`            |
| `r` | 对象引用（object reference）      | `r:1;`            |
| `C` | 自定义序列化对象（实现 `Serializable`） | `C:...`           |

## 反序列化漏洞

也叫做**对象注入**，当程序在进行反序列化时，会自动调用一些函数，通过控制传入函数的参数，可以将一些恶意代码注入到函数中，导致反序列化漏洞的产生

也就是，在执行`unserialize()`时，会自动调用某些**魔术方法(magic method)**

在序列化中，只会输出属性名和属性的值，**不会输出方法**（public function之类）

条件：
1. `unserialize()`函数的参数是可控的
2. 存在可利用的魔术方法

## 属性赋值

要利用反序列化漏洞，必须向`unserialize()`函数传入构造的序列化数据（定义合适的属性值）

## 费马分解

**费马分解(fermat's factorization method)可以将合数分解为两个因数的乘积**,设有一个整数n,有:
$$
n=a^2-b^2\\
n=(a+b)(a-b)
$$
设p,q,有:
$$
\begin{cases}
p=a+b\\
q=a-b
\end{cases}
$$
即:
$$
\begin{cases}
a=\frac{p+q}{2}\\
b=\frac{p-q}{2}
\end{cases}
$$
假设p和q非常接近,则需证明:
$$
b^2=a^2-n
$$
成立即可,或是:$b^2$是一个完全平方数即可

a从哪里开始取值,如下需要满足:
$$
b^2=a^2-n>0\\
a>\sqrt{n}
$$
即:**从$a=\lceil \sqrt{n} \rceil$开始,依次判断$b^2=a^2-n$是否完全平方**

如何得到`ab`?

我们设`a+b=P`,`ab=Q`,且:
$$
\begin{cases}
p_1+p_2=2gP+2\\
p_1\times p_2=N
\end{cases}

x^2-(2gP+2)x+N=0

$$
\Delta=(2gP+2)^2-4N
$$

h=2gab+a+b\\
h=2gQ+P\\
Q=\frac{h-P}{2g}\\
Q=\frac{h}{2g}-\frac{P}{2g}
$$
注意到:$\frac{P}{2g}$这一项是**很小的**,g约为500位,Q约为524位,估算一下有:
$$

# 向量
一组数的表示方法：**向量**(vector)

行向量$(1,2)$和列向量$\begin{pmatrix} 1\\2 \end{pmatrix}$,其中列向量也可以写为:$(1,2)^T$

首先是将向量封装为一个**类**

```python
class Vector:  
  
    def __init__(self,lst):  
        self._values=lst  
  
    def __getitem__(self, index): #实现向量索引  
        return self._values[index]  
  
    def __len__(self):  
        return len(self._values)  
  
    def __repr__(self):  
        return "Vector({})".format(self._values)  
  
    def __str__(self):  
        return "({})".format(", ".join(str(e) for e in self._values))
```

## 定义一个类的基本结构

```python
class Vector:
	def __init__(self,lst):
		self._values=lst
	
	def __len__(self):
		return len(self._values)
	
	def __str__(self):
		return "({})".format(", ".join(map(str,self._values)))
```

 **`self`是什么?**

指的是"**当前这个对象本身**".定义方法时第一个参数必须是self

**`__init__`构造方法**

对象一创建就自动执行,用来初始化属性
```python
v=Vector([1,2,3]) #自动调用__init__(v,[1,2,3])
```

**属性存在`self`上**
```python
self._values=lst
```
意思是,这个对象的`_values`属性等于`lst`
正好学了php反序列化,上面的类似于:
```php
$this->_values=$lst
```
比如传入一个`v=Vector([1,2,3])`,`lst`就是传入的`[1,2,3]`,被赋值给了这个类的一个属性`_values`

像上面的`return "({})".format(", ".join(map(str,self._values)))`运用了**字符串格式化**,比如:
```python
print("{}+{}={}".format(1,2,3))
#输出:1+2=3
```


## 定义一个零向量

首先是一个概念:`@classmethod`定义一个**类方法**
```python
class MyClass:
	@classmethod
	def my_class(cls,arg1,arg2):
		#cls指向这个类本身
```
- `cls`指向类本身(不是**实例**)
- 可以通过**类**或是**实例**调用(如:`MyClass.method()`或是`obj.method()`)
- 不能访问实例属性,只能访问类属性/类方法

定义**零向量**：
```python
@classmethod
    def zero(cls,dim):
        return cls([0]*dim)
```

- `@classmethod`定义类方法,第一个参数是`cls`(类本身)
- `dim` 指**维度**
- `[0]*dim` 生成一个长度为`dim`,且元素全为`0`的数组
- `cls([0]*dim)`快捷创建了一个**实例**,等效于`Vector([0,0,0,0,...])`

创建零向量的实例如下:
```python
zero_1=Vector.zero(2)
#(0,0)
```

$$
## 单位向量(unit vector)

单位向量的长度是`1`
$$
||\vec{u}||=\sqrt{u_1^2+u_2^2+u_n^2}\\
\hat{u}=\frac{1}{\vec{u}}\cdot \hat{u}=\left(\frac{u_1}{||\vec{u}||} , \frac{u_2}{||\vec{u}||},\cdots ,\frac{u_n}{||\vec{u}||} \right)
$$
对于单位向量来说,长度总为1,只表示方向

根据$\vec{u}$得到$\hat{u}$的过程叫做**归一化**或是**规范化**(normalization)

只由0,1组成的单位向量:

<font color='red'>标准单位向量 Standard Unit Vector</font>

即指向坐标轴正方向的单位向量

二维空间中有**两个标准向量**
$$
\vec{e_1}=(1,0),\vec{e_2}=(0,1)
$$
三维空间中有**三个标准向量**
$$
\vec{e_1}=(1,0,0),\vec{e_2}=(0,1,0),\vec{e_2}=(0,0,1)
$$

```python
def __norm__(self):
```

## 得到一个向量的单位向量

```python
def normalize(self):
        return Vector([e/self.norm() for e in self])
```

## 向量的点乘/内积

$$
\vec{u_1}\cdot \vec{u_2}=\begin{pmatrix} u_1\\u_2\\ \cdots \\u_3 \end{pmatrix} \cdot \begin{pmatrix} v_1\\v_2\\ \cdots \\v_3 \end{pmatrix} =u_1v_1+u_2v_2+\cdots + u_n\cdot v_n \\=||\vec{u}||\cdot||\vec{v}||\cdot \cos\theta
$$
**实现向量的点乘**
```python
def dot(self,another):
        assert len(self)==len(another),\
            "error in dot product:the length of vectors must be same"
        return sum(a*b for a,b in zip(self,another))
```
