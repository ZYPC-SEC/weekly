## 4.git发送文件的方法
### 1..gitignore
* 输入.env 为了不被上传到github
* 之后加入文件名+/即可避免被误提交

### 2.commit提交
* 可以在源代码功能上面的更改消息框内填写每次更改的批注
* 下面的图表可以看见每次的更改链路
* ID分为长和短两种，方便告知AI

### 3.branch分支
* 分支分为main分支和feature分支
* 可以根据历史分支，最新文件和分支创建分支，也可以删除分支并且合并分支
* HEAD指的是切换到那个分支就指向哪个分支的最新文件，也同时可以不指向任何分支

### 4.WorkTree
* 可以连接多个文件夹，进行合并和修改

### 5.Merge Conflict(合并冲突)
* 因为分支都被改了同一个位置
* 扔给agent合并时它会给你选项

### 6.Git Areas
* Working Directory（工作区）
* local Repository(本地仓库)
* Remote Repository（远端仓库）
* git clone 由3到1 由远端仓库保存到本地
* git add +git commit 由工作区改动保存到本地仓库
* git push 将本地仓库改动传到远端仓库
* git pull将远端的改动合并到本地
* git merge 将改动由本地转到工作区
* Staging （暂存区）（工具已自动简化）

### 常用方法
* 1.若要更改远端仓库文件，可以先git clone进Vscode，更改后再commit
* 2.若要直接上传文件给远端，需要先给文件初始化，再commit，同时要选择是公开还是私有
* 3.远端的更改，可以再源代码窗口用git pull把远端的提交拉回来
* 当main 和origin main在一起，咋说明两仓库已同步

## GitHub
* Releases记录版本，Assets是作者打包的要下载的包
* Fork是将项目保存一份到自己仓库，方便进行学习更改
