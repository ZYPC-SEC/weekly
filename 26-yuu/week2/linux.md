# Linux

一些基础的linux命令，一些运维比较常用的linux命令

## 1.目录、路径和基础命令。

### 1.认识命令提示符：

首先举个例子：我这里所使用

```bash
[qiao@kali ~]$
```

- `qiao`：当前用户名

- `kali`：主机名

- `~`：当前位于用户主目录

- `$`：普通用户；如果是 `#`，表示 `root` 管理员用户

  注意：看到 # 的时候要注意，因为很多的命令将会影响整个系统。

### 2.路径基础

| 写法       | 含义                                |
| ---------- | ----------------------------------- |
| `/`        | 系统根目录                          |
| `~`        | 当前用户的主目录，例如 `/home/qiao` |
| `.`        | 当前目录                            |
| `..`       | 上一级目录                          |
| `/var/log` | 绝对路径，从 `/` 开始               |
| `logs`     | 相对路径，从当前目录开始            |

### 3.核心的五个命令

#### 1. pwd

显示当前所在的目录：`pwd`

#### 2.whoami

显示当前用户名：`whoami`

#### 3.ls

列出目录内容：`ls`

```bash
ls
ls -l
ls -lah
```

`ls -lah` 的含义：

- `-l`：详细列表
- `-a`：显示隐藏文件，包括 `.` 和 `..`
- `-h`：以更易读的方式显示文件大小

#### 4.cd

切换目录：`cd`

```bash
cd /var/log     # 进入 /var/log
cd ~            # 回到主目录
cd ..           # 返回上一级
cd -            # 返回上一次所在目录
cd              # 也回到主目录
```

#### 5.clear

清屏：`clear` 只是清除终端显示，不会删除任何内容。

#### 补充：

```bash
man ls
ls --help
```

- `man 命令`：打开完整手册，按 `q` 退出
- `命令 --help`：快速查看常用参数

## 2.文件与目录的创建，复制，移动和删除。

使用 `mkdir`、`touch`、`cp`、`mv`、`rm`、`rmdir` 完成日常文件管理。

### 1.创建目录

```bash
mkdir test
```

创建多级目录时使用 `-p`：

```bash
mkdir -p ~/linux-practice/day2/notes
```

- `-p`：父目录不存在时自动创建
- 目录已经存在时也不会报错

另外，`mkdir test{1,2,3}` 可以一次创建 `test1 test2 test3`。

### 2.创建空文件

```bash
touch report.txt
touch notes/todo.txt notes/linux.txt
```

`touch` 的常见用途是创建空文件；如果文件已存在，它会更新文件的修改时间。

文件名包含空格时要加引号：

```bash
touch "my notes.txt"
```

### 3.复制

```bash
cp report.txt report-copy.txt
```

复制到指定目录：

```bash
cp report.txt backup/
```

复制整个目录必须加 `-r`：

```bash
cp -r notes notes-backup
```

常用参数：

| 参数 | 作用                             |
| ---- | -------------------------------- |
| `-r` | 递归复制目录                     |
| `-i` | 覆盖前询问                       |
| `-a` | 保留权限、时间等属性，常用于备份 |

> `cp` 默认可能直接覆盖同名文件。重要文件建议使用 `cp -i`。

### 4.移动与重命名

`mv` 同时负责“移动”和“重命名”。

```bash
mv linux.txt bash.txt
```

移动文件到目录：

```bash
mv todo.txt notes/
```

重命名目录：

```bash
mv notes notes-old
```

### 5.删除

删除文件：

```bash
rm report.txt
```

删除前查询：

```bash
rm -i report.txt
```

删除空目录：

```bash
rmdir empty-dir
```

递归删除目录及其中所有内容：

```bash
rm -r notes-old
```

删除前逐个确认：

```bash
rm -ri notes-old
```

### 重要安全提醒

- Linux 命令行删除通常**没有回收站**，删除后很难恢复。
- `-f` 表示强制删除，不提示；初学阶段不要随便使用。
- 不要执行来源不明的 `rm -rf` 命令。
- 特别注意变量和通配符，例如 `rm -rf ~/*` 可能删除整个主目录中的文件。

## 3.查看文件内容与搜索

### 1.`cat`:显示文件内容

```bash
cat app.log
cat -n app.log
```

- `cat 文件名`：输出整个文件
- `cat -n 文件名`：显示内容并加上行号
- `cat file1 file2`：依次显示多个文件

适合查看小文件。如果文件很大，不要直接使用 `cat`，否则大量内容会刷满终端，这时应使用 `less`。

### 2. `less`：分页查看

```bash
less app.log
```

进入 `less` 后常用操作：

| 操作                   | 作用             |
| ---------------------- | ---------------- |
| `Space` 或 `Page Down` | 向下翻一页       |
| `b` 或 `Page Up`       | 向上翻一页       |
| `g`                    | 跳到文件开头     |
| `G`                    | 跳到文件末尾     |
| `/error` 后按回车      | 搜索 `error`     |
| `n`                    | 跳到下一个匹配项 |
| `N`                    | 跳到上一个匹配项 |
| `q`                    | 退出 `less`      |

查看大文件、日志时，优先使用 `less`。

### 3. `head`：查看开头部分

```bash
head app.log
head -n 3 app.log
```

- 默认显示前 10 行
- `-n 3`：只显示前 3 行

### 4. `tail`：查看末尾部分

```bash
tail app.log
tail -n 2 app.log
```

- 默认显示最后 10 行
- `-n 2`：只显示最后 2 行

实时跟踪日志：

```bash
tail -f app.log
```

`-f` 会持续显示新追加的内容，按 `Ctrl + C` 停止。

### 5. `grep`：按内容搜索

搜索包含 `ERROR` 的行：

```bash
grep "ERROR" app.log
```

常用参数：

| 参数 | 作用                 |
| ---- | -------------------- |
| `-i` | 忽略大小写           |
| `-n` | 显示行号             |
| `-v` | 显示不匹配的行       |
| `-c` | 只统计匹配行数       |
| `-r` | 递归搜索目录中的文件 |

示例：

```bash
grep -n "ERROR" app.log
grep -in "error" app.log
grep -v "INFO" app.log
grep -c "ERROR" app.log
grep -r "alice" .
```

最后一条命令表示：从当前目录开始，递归搜索包含 `alice` 的内容。

### 6. `wc`：统计文件

```bash
wc -l app.log
```

- `-l`：统计行数
- `-w`：统计单词数
- `-c`：统计字节数

最常用的是 `wc -l`，例如统计日志有多少行。

## 4. 重定向与管道

- `>`：覆盖写入文件
- `>>`：追加内容
- `2>`：把错误信息写入文件
- `2>&1`：合并正常输出和错误输出
- `<`：把文件作为命令输入
- `|`：管道，把前一个命令的输出交给后一个命令
- `tee`：同时显示并保存结果
- `/dev/null`：丢弃输出

## 5.用户、用户组、权限与 `sudo`

### 1.查看当前用户

```bash
whoami
id
groups
```

`id` 的输出可能类似：

```
uid=1000(kali) gid=1000(kali) groups=1000(kali),27(sudo)
```

含义：

- `uid`：用户 ID
- `gid`：主用户组 ID
- `groups`：用户所属的全部组
- `root` 的 UID 是 `0`
- 普通用户通常是 UID `1000` 或更大的数字

如果提示符是：

```
root@kali:~#
```

说明你当前是 `root` 用户。`root` 权限极高，执行命令前必须确认命令和目标路径。

### 2.文件权限

执行：

```
ls -l
```

可能看到：

```
-rw-r--r-- 1 kali kali 132 Jan 10 10:00 report.txt
```

重点看第一列：

```
-rw-r--r--
```

分成四部分：

```
-   rw-   r--   r--
│    │     │     │
│    │     │     └── 其他人权限
│    │     └──────── 用户组权限
│    └────────────── 文件所有者权限
└─────────────────── 文件类型
```

文件类型：

| 字符 | 含义     |
| ---- | -------- |
| `-`  | 普通文件 |
| `d`  | 目录     |
| `l`  | 符号链接 |

后续三组权限中：

| 字符 | 文件上的含义   | 目录上的含义                   |
| ---- | -------------- | ------------------------------ |
| `r`  | 读取文件内容   | 列出目录内容                   |
| `w`  | 修改文件内容   | 在目录中创建、删除、重命名文件 |
| `x`  | 执行程序或脚本 | 进入目录、访问目录中的文件     |

特别注意：**删除文件主要取决于文件所在目录的 `w` 和 `x` 权限，而不是文件本身的 `w` 权限。**

对普通目录而言，要删除目录中的文件，需要对目录同时具有写权限和执行权限。

### 3.修改权限：`chmod`

#### 符号方式

用户类别：

| 符号 | 含义         |
| ---- | ------------ |
| `u`  | 所有者 user  |
| `g`  | 用户组 group |
| `o`  | 其他人 other |
| `a`  | 所有人 all   |

操作用户：

| 符号 | 作用           |
| ---- | -------------- |
| `+`  | 增加权限       |
| `-`  | 删除权限       |
| `=`  | 设置为指定权限 |

示例：

```bash
chmod u+x demo.sh
chmod g-w report.txt
chmod o=r report.txt
chmod a+x script.sh
chmod u=rw,g=r,o= report.txt
chmod g+w,o-r report.txt
```

#### 数字方式

权限对应数字：

```
r = 4
w = 2
x = 1
```

三位数字分别代表：

```
所有者  用户组  其他人
  7       5      5
```

常见组合：

| 数字  | 权限        | 常见用途                       |
| ----- | ----------- | ------------------------------ |
| `600` | `rw-------` | 只有自己能读写                 |
| `640` | `rw-r-----` | 自己读写，同组可读             |
| `644` | `rw-r--r--` | 普通文件常用                   |
| `700` | `rwx------` | 只有自己能访问的目录           |
| `755` | `rwxr-xr-x` | 目录、可执行程序常用           |
| `777` | `rwxrwxrwx` | 所有人都能读写执行，通常不安全 |

示例：

```bash
chmod 600 private.txt
chmod 644 report.txt
chmod 755 demo.sh
```

> 不要为了“解决权限问题”直接执行 `chmod -R 777`。这会大幅降低系统安全性，也经常掩盖真正的问题。

### 4.`chown`和`chgrp`

查看所有者与用户组：

```bash
ls -l
```

修改文件所有者和用户组：

```bash
sudo chown 用户名 文件名
sudo chown 用户名:用户组 文件名
```

例如：

```bash
sudo chown kali:kali report.txt
```

递归修改目录及其内容：

```bash
sudo chown -R kali:kali 目录名
```

单独修改用户组：

```bash
sudo chgrp 组名 文件名
```

> `chown -R` 会修改整个目录树。执行前先用 `pwd` 和 `ls -ld 目录名` 确认位置，不要对 `/`、`/etc`、`/usr` 等系统目录随意执行。

## 6.进程与任务管理

## 进程基础

每当一个程序运行，Linux 就会为它创建一个进程，并分配一个唯一的 **PID**（进程 ID）。

常见进程状态：

| 状态 | 含义                             |
| ---- | -------------------------------- |
| `R`  | 正在运行或等待 CPU               |
| `S`  | 可中断睡眠，等待事件             |
| `D`  | 不可中断睡眠，通常等待磁盘等 I/O |
| `T`  | 已停止                           |
| `Z`  | 僵尸进程，等待父进程回收         |

进程和终端任务不是完全相同的概念：

- 每个进程都有 PID
- `jobs` 查看的是当前 Shell 管理的任务
- 一个任务可能包含多个进程

### `ps`：查看进程快照

### `top`：动态查看进程

`top` 会持续刷新，显示 CPU、内存和进程情况。

常用交互键：

| 按键 | 作用                          |
| ---- | ----------------------------- |
| `q`  | 退出                          |
| `P`  | 按 CPU 使用率排序             |
| `M`  | 按内存使用率排序              |
| `1`  | 展开或收起每个 CPU 核心的数据 |
| `u`  | 按用户名过滤进程              |
| `k`  | 向指定 PID 发送信号           |
| `h`  | 显示帮助                      |

### 信号与 `kill`

`kill` 的真实作用是向进程发送信号，不一定只是“杀死”。

常用的信号：

| 信号      | 编号 | 作用                           |
| --------- | ---- | ------------------------------ |
| `SIGHUP`  | 1    | 挂断，常用于让程序重新加载配置 |
| `SIGINT`  | 2    | 中断，相当于按 `Ctrl + C`      |
| `SIGKILL` | 9    | 强制杀死，进程无法捕获或忽略   |
| `SIGTERM` | 15   | 请求进程正常终止，默认信号     |

## 7.软件安装与基础的网络命令

### 1. `apt`：软件包管理

Kali 基于 Debian，使用 `apt` 管理软件包。

### 查看当前系统和软件信息

```bash
apt --version
apt list --installed | head
apt show curl
apt search curl | head
command -v curl
```

说明：

- `apt list --installed`：查看已安装软件
- `apt show 包名`：查看软件包信息
- `apt search 关键词`：搜索软件包
- `cmand -v 命令`：查看命令是否已安装及其路径

### `update` 和 `upgrade` 的区别

```bash
sudo apt update
```

更新的是**软件包索引**，告诉系统软件仓库里有哪些新版本，不会升级已安装的软件。

```bash
sudo apt upgrade
```

根据更新后的索引升级已安装软件。

| 命令               | 作用                           |
| ------------------ | ------------------------------ |
| `apt update`       | 更新软件包列表                 |
| `apt upgrade`      | 升级已安装软件                 |
| `apt install 包名` | 安装软件                       |
| `apt remove 包名`  | 卸载软件，可能保留配置         |
| `apt purge 包名`   | 卸载软件并删除配置             |
| `apt full-upgrade` | 完整升级，可能安装或移除依赖包 |

### 安装与卸载示例

```bash
sudo apt install 软件包名
sudo apt remove 软件包名
sudo apt purge 软件包名
```

### 2. `ip`：查看网卡、IP 和路由

### 查看所有网卡和 IP

```bash
ip addr
ip address
```

简略格式：

```bash
ip -br addr
```

常见接口：

- `lo`：本地回环接口
- `eth0`：有线网卡
- `wlan0`：无线网卡

你通常会看到：

```
127.0.0.1/8
```

这是本机回环地址，只能在本机内部访问。

### 查看路由和默认网关

```bash
ip route
```

可能看到：

```
default via 192.168.1.1 dev eth0
192.168.1.0/24 dev eth0
```

`default via ...` 表示默认网关。访问互联网时，如果找不到更具体的路由，流量会发给这个地址。

### 3. `ping`：测试网络连通性

测试本机回环：

```bash
ping -c 4 127.0.0.1
```

测试公网地址：

```bash
ping -c 4 1.1.1.1
```

测试域名：

```bash
ping -c 4 example.com
```

`-c 4` 表示只发送 4 个 ICMP 请求。如果不加 `-c`，Linux 会持续发送，按 `Ctrl + C` 停止。

注意：

- 能 `ping` 通，不代表对应服务一定可用。
- `ping` 不通，也不一定代表网络完全断开，因为有些主机或防火墙会屏蔽 ICMP。
- 只测试自己拥有或公开允许测试的地址，不要随意扫描他人网络。

## 4. 检查 DNS

先查看系统使用的 DNS 配置：

```bash
cat /etc/resolv.conf
```

使用系统解析器查询域名：

```bash
getent hosts example.com
```

如果：

```bash
ping -c 2 1.1.1.1
```

可以连通，但：

```bash
ping -c 2 example.com
```

无法解析，那么问题很可能在 DNS，而不是基础网络连接。

如果系统安装了 `dig`，也可以使用：

```bash
dig example.com
```

但 Kali 上不一定默认安装，所以 `getent` 更适合作为通用检查方式。

### 5. `ss`：查看网络连接和监听端口

`ss` 是 `netstat` 的现代替代品。

查看正在监听的 TCP 和 UDP 端口：

```bash
ss -tuln
```

参数含义：

| 参数 | 作用                       |
| ---- | -------------------------- |
| `-t` | TCP                        |
| `-u` | UDP                        |
| `-l` | 只显示监听端口             |
| `-n` | 显示数字端口，不转换服务名 |
| `-p` | 显示对应进程               |

显示进程信息：

```bash
sudo ss -tulpn
```

查看已建立的 TCP 连接：

```bash
ss -tn
```

常见端口：

| 端口   | 服务             |
| ------ | ---------------- |
| `22`   | SSH              |
| `53`   | DNS              |
| `80`   | HTTP             |
| `443`  | HTTPS            |
| `8000` | 本课本地测试服务 |

监听地址很重要：

- `127.0.0.1:8000`：只接受本机访问
- `0.0.0.0:8000`：监听所有 IPv4 网卡，局域网其他主机可能访问
- `[::]:8000`：监听 IPv6 所有地址

### 6. `curl`：发送 HTTP 请求

查看网页内容：

```bash
curl http://example.com
```

只查看响应头：

```bash
curl -I https://example.com
```

常用参数：

| 参数                  | 作用                   |
| --------------------- | ---------------------- |
| `-I`                  | 只获取响应头           |
| `-L`                  | 自动跟随重定向         |
| `-v`                  | 显示详细请求和响应过程 |
| `-o 文件`             | 保存到文件             |
| `-s`                  | 安静模式，减少进度信息 |
| `--connect-timeout 5` | 连接超时时间设为 5 秒  |

示例：

```bash
curl -I https://example.com
curl -L https://example.com
curl -o page.html https://example.com
curl -sS https://example.com
```
