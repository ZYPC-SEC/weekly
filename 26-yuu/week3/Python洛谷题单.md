### P1001 A+B Problem

俩数相加，为了方便直接一行输入。用到 map 函数对于所有值操作，split（）函数用于对数值间进行一个空格操作。

```Python
a,b = map(int,input().split())
print(a+b)
```


### P5704 【深基2.例6】字母转换

就是一个简单的输入加大小写的转化，先输入字符的时候要确保不会读入空格，所以使用 strip（）函数进行一个清除。最后的代码实现为：

```Python
n = input().strip()
print(chr(ord(n) - 32))
```

chr（）函数重新转化为字符，ord（）函数的作用是将输入的 n 转化为 ASCLL码，然后相减。

当然除此之外 Python 里面还内置了一个·专门用来转化大小写的函数`n.upper()` 会直接把小写字母变成大写字母，这个会比较安全，因为如果是字符直接转化，不是字符的话直接留在原地，不去改变它。

```Python
n = input().strip()
print(n.upper())
```
