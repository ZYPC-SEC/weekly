# python

print***：了解了```print("")```其原理和c与语言的printf差不多但不同的是print自带了换行符的效果。

***注释：***学习了注释符，这里与c不同它的注释符为“#”且只有#在引号外才能起到注释的效果，否则只是一个简单的井号。
***数字与文字：***分别输入了```print（1+1)```和```print("1+1")```这两个的输出结果截然不同第一个输出的是这个运算式的结果，第二个输出的是运算式，原因在于引号，引号内，无论是字符还是数字同一按照文字处理，只有在引号外数字才会执行运算式,做数学运算，因此想要打印出```6+2=8```这种的文字和结果一起出来的效果就需要```print("6+2=",6+2)```
（print里我们使用逗号隔开在这里会自动添加一个空格上去，为了整体较为美观可以在前面的引号数字式里也加入空格保持一致）其实关于我们输出的到底式整数还是字符串可以用函数type()来查看类型，例如我们输入

```
print(type(10))
print(type("10"))
```

它的输出就是

```
<class 'int'>
<class 'str'>
```

int（integer）类型是整数可以进行数学计算，str（string）类型是字符串，他只是一段文字
***变量：***这里我感觉是与c语言差距较大的地方，因为它竟然可以不用声明变量类型！用一个最简单的例子

```

```

看见我们并没有声明变量类型，但是有一个注意到点就是引号（没错又是他）如果变量为name此时把name放进引号里他只会按照name这个文字输出而不是他这个变量所代表的xiaoming，就是因为引号内的字符类型为str他只是一段文字。
声明变量还有的好处：

- 可以参与计算，例如

***input：***

input类似于c里面的scanf，但比他要简单许多，举个简单的例子，想让用户输入一个数字或名字只需要```bianliang = input（“请输入文本”）```就行这时输入的字符就会存进bianliang这个变量里面等待调用。但是这里有个值得注意的一点就是input里的永远是文字也就是str类型，那么我们想让input里的值参与运算怎么办呢，这时我们就需要声明类型把文字转换为数字，即int(input())这样input它那到的就是数字可以进行数字计算了

***if判断：***

这里的if和c里面的差不多，但是有个缩进的概念需要强调：在 Python 里，缩进不是排版好看，而是**语法的一部分**。Python 靠缩进来判断：哪些代码属于 `if`，哪些不属于。这里用一个简单的代码来演示一下

```python
age=20

if age >= 18:
    print("chengnian")
else:
    print("weichengnian")
```

可以看见if和else下面的两个print是分别香油移了四格的，用----表示四个空格就是

```python
age=20

if age >= 18
----print("chengnian")
else:
----print("weichengnian")
```

这四个空格就是缩进，即条件成立时，执行 `if` 下面缩进的那一块；条件不成立时，跳过它，执行 `else` 下面缩进的那一块。

同时这里也涉及到了比较运算符，它和c语言的差不多，这里列一下常用的比较运算符

```
>    大于
<    小于
>=   大于等于
<=   小于等于
==   等于（两个等号）
!=   不等于
```

当然python里面也有和c一样的else if的东西——elif

其基本结构是这样的

```python
if 条件1:
    代码1
elif 条件2:
    代码2
elif 条件3:
    代码3
else:
    代码4
```

他会从上往下逐个判断：1不符和看2，2不符合看3，3不符合执行else

***循环***

- for循环：

for循环的循环结构为

```
for 变量 in 一串值:
    循环体
```

这个结构里的变量为循环变量，for语法需要变量去把下面循环体的每一轮的值接住。

in是for循环里核心的地方它表示“从...... 里面依次取值”，但是他不负责赋值，赋值是由整个for......in,,,,,,语句负责：每取一个值，就自动赋给前面的变量 `i`，然后执行循环体。

一串值指的是range（1，6）或range（5）这种的，前者指的是从一开始循环到六停止，也就是分别循环1，2，3，4，5这5次，不循环第6次的原因是以为range的规则：包含起点不包含终点。也就是说想要循环第6次需要改为range（1，7）。而后者range（5）的意思是循环5次这里分别用这两个方法进行演示

range（1，6）

```
for i in range(1,6)
    print(i)
```

range (5)

```
for i in range(5)
    print("hello")
```

第一个执行的结果是

```
1，2，3，4，5
```

第二个的结果为

```
hello
hello
hello
hello
hello
```

这里就有一个比较抽象的点，明明变量i被分别赋予了1，2，3，4，5为什么这里只有5个hello，它的主要原因是因为for循环的整体逻辑：一旦循环变量被range赋予新值，循环就执行一次，而这个执行指的是执行循环体，回看代码，我们的循环体是```print("hello")```所以我们的逻辑就是for检测到range还有下一个值，i被range赋予新值，执行循环体，打印“hello”

可以看见for执行的是循环体内容，只有当循环体里有i的参与时，i的值才会起作用，否则就是i 仍然每轮都会被赋值，但它的值不会产生任何可见效果（i的值被忽略了）。当然，如果说循环体里没有这个值，也就是说不需要变量的值，我们可以写成```for _ in range(5):```，表示“我不关心当前值，只要重复循环5次。”

## 2.basic_3

打开题目，f12收集信息，题目说明输入错误会封一小时先把这个环境关掉，在源码中这个环境是在js里写的

```
function setLockout() {
    localStorage.setItem('lockoutUntil', Date.now() + 60*60*1000);
}
function isLocked() {
    var until = localStorage.getItem('lockoutUntil');
    return until && Date.now() < parseInt(until, 10);
}
```

意思是他是在浏览器里写了一个时间截，大于这个时间就会显示红字并禁止输入，在控制台输入

```
localStorage.clear();   // 清空浏览器给这个网站存的所有本地数据
location.reload();      // 刷新页面
```

关掉环境，然后读源码，里面我们发现了这样一段

```
expected = eval(password);     // 先算出真密码是啥
```
