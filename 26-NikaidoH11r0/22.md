# 二     主要学习内容

## 1. 基本Linux命令

Linux命令的组成格式一般为  `命令` `[选项]` `[目标]`

> Tips：选项分两种，短选项用一个短横（`-l`），长选项用两个短横（`--help`）。短选项之间可以合并，如`-l -a`写成`-la`；长选项不能合并。

### 1.0 安装并使用WSL

以管理员身份打开PowerShell，执行：

``` powershell
wsl --install
```

这样会默认下载Ubuntu。如果想装别的Linux发行版可以在后面加参数，如：

``` powershell 
wsl --install -d kali-linux
```

这样会下载Kali（一种集成了很多安全工具的Linux发行版）。

#### 用VS Code连接WSL

用VS Code可以直接在Windows里编辑Linux下的文件：

1. 在VS Code扩展里搜`WSL`，安装微软官方的`WSL`扩展；
2. 点左下角的`><`图标，选`Connect to WSL`（或者`New WSL Window`）；
3. 连上之后左下角会显示`WSL: kali-linux`，此时终端、资源管理器里的文件树都是Linux那边的；
4. 也可以在WSL终端里直接执行`code .`，它会自动用VS Code打开当前目录。

> Tips：连上WSL之后打开的终端默认就是Linux的shell，不用再手动切；`code 文件名`可以直接打开单个文件。

### 1.1 查看与切换

#### 提示符怎么看

进入终端后，命令行最左边的一串东西就是提示符，形如：

```
NikaidoHiro@DESKTOP-XXXX:~$
```

| 部分        | 含义                                                         |
| ----------- | ------------------------------------------------------------ |
| `NikadoHiro` | 当前登录的用户名                                             |
| `DESKTOP-XXXX` | 主机名                                                    |
| `~`         | 当前所在目录，`~`就是家目录（`/home/用户名`），换成别的目录会直接显示路径 |
| `$`         | 普通用户；如果是`#`，说明当前是root，权限最大，操作要小心     |

> Tips：`~`是家目录的简写，root用户的家目录是`/root`，普通用户是`/home/用户名`，两者不通用。

- `pwd`

  - 显示当前所在目录的完整路径。

  > Tips：`pwd`命令一般没有`[选项]`和`[目标]`

- `ls`

  - 列出当前文件夹下的所有文件和目录。

  | 常见用法 | 效果                                           |
  | -------- | ---------------------------------------------- |
  | `ls -l`  | 显示详细列表，包括权限，所有者，大小，修改时间 |
  | `ls -a`  | 显示隐藏文件（以.开头的文件）                  |
  | `ls -h`  | 显示文件大小                                   |

  > Tips：两个短选项可以合并，如`ls -l -a`与`ls -la`是等效的。`-h`单独用没什么意义，要配合`-l`写成`ls -lh`，大小才会显示成`4.0K`这种人能看懂的形式。
  >
  > `ls -l`输出最前面那串`drwxr-xr-x`是权限位，第一个字符是`d`就表示目录、是`-`就表示普通文件。

- `cd`

  - 切换所在目录

  | 常见用法   | 效果                                                   |
  | ---------- | ------------------------------------------------------ |
  | `cd 123/a` | 进入 123/a                                             |
  | `cd ..`    | 进入上一级目录，也可以`cd ../123进入`上级目录的123文件 |
  | `cd`       | 回到家目录                                             |
  | `cd -`     | 回到上一次所在的目录（在两个目录间反复横跳很方便）     |
  | `cd /`     | 进入根目录                                             |

  > Tips：绝对路径最前面有`/`，相对路径最前面没有
  >
  > 按`Tab`键可以自动补全路径，连按两下会列出所有候选，能省掉大量打字和拼写错误。

- `clear`

  - 清理当前屏幕的所有输出

  > Tips：`Ctrl+L`可以达到相同的效果

- `history`

  - 列出本次会话（以及之前保存在`~/.bash_history`中）的命令历史。

  > 所以说`clear`只会清理屏幕输出，如果还想再看可以用`history`调出来
  >
  > Tips：配合`!`可以快速重跑，`!12`执行历史里第12条命令，`!!`执行上一条，`Ctrl+R`可以按关键字反向搜索历史命令。`history -c`才是真正清空历史记录。

#### 帮助系统：man 与 --help

命令太多记不住是常态，重点是知道怎么现查：

| 方式                  | 效果                                                         |
| --------------------- | ------------------------------------------------------------ |
| `ls --help`           | 快速看简版用法，直接输出在终端里，适合只想快速查参数 |
| `man ls`              | 打开完整手册，分区详细，还有示例和环境说明                   |
| `man 1 ls`            | 指定看第1区的man手册（1是普通命令，5是文件格式，8是系统管理命令） |
| `clear` / `Ctrl+L`    | 清屏，man界面里也能用                                        |
| `q`                   | 退出手册                                                     |

`man`界面里的常用操作：

| 按键        | 效果              |
| ----------- | ----------------- |
| `空格`/`f`  | 向下翻一页        |
| `b`         | 向上翻一页        |
| `/关键字`   | 向下搜索关键字    |
| `n` / `N`   | 跳到下一个/上一个匹配 |
| `g` / `G`   | 跳到开头/结尾     |
| `q`         | 退出              |

> Tips：`man`默认是英文的，Kali上可以`sudo apt install -y manpages-zh`装中文手册，但很多术语还是英文看着更顺。
>
> 实在懒得翻手册，`命令 --help`＋搜索引擎基本能解决九成问题。

### 1.2 增删改查 

+ `touch`

  + 创建空文件/更新文件的时间戳

  > Tips：对已存在的文件执行`touch`不会清空内容，只会把它的最后修改时间改成现在；`touch -d "2024-01-01" 1.txt`可以指定时间。

+ `mkdir`

  + 创建目录

  | 常见用法         | 效果                                                         |
  | ---------------- | ------------------------------------------------------------ |
  | `mkdir -p a/b/c` | 递归创建目录（不带-p时，如果`a`不存在，`mkdir a/b/c`会直接报错） |
  | `mkdir -m 700 a` | 创建的同时指定权限（`700`是代表权限的参数）                  |

  > Tips：`touch`和`mkdir`可以同时创建多个文件/文件夹，如`touch 1.txt 2.txt 3.txt`

+ `cp`

  + 复制

  | 常见用法            | 效果                            |
  | ------------------- | ------------------------------- |
  | `cp 1.txt 2.txt`    | 复制文件并改名                  |
  | `cp 1.txt /a/`      | 复制到目录，文件名不变          |
  | `cp 1.txt /a/2.txt` | 复制到目录并改名                |
  | `cp -r aaa /a/b`    | 递归复制整个目录`aaa`到`/a/b`下 |
  | `cp -i 1.txt 2.txt` | 目标已存在时先询问，防止覆盖    |
  | `cp -v 1.txt /a/`   | 显示复制过程                    |
  | `cp -a aaa /a/b`    | 归档模式，连权限、时间戳一起复制 |
  | `cp *.txt /a/`      | 借助通配符一次复制多个文件      |

  > Tips：复制目录必须加`-r`（递归），否则会提示`omitting directory`。`cp`默认会直接覆盖同名文件且**不给任何提示**，重要操作前记得加`-i`。

+ `mv`

  + 移动 / 重命名（这两个操作在Linux里是同一个命令）

  | 常见用法            | 效果                                   |
  | ------------------- | -------------------------------------- |
  | `mv 1.txt 2.txt`    | 改名（目标不存在时）                   |
  | `mv 1.txt /a/`      | 移动到目录，文件名不变                 |
  | `mv 1.txt /a/2.txt` | 移动到目录并改名                       |
  | `mv aaa /a/b`       | 移动整个目录，不需要`-r`               |
  | `mv -i 1.txt 2.txt` | 同名覆盖前询问                         |
  | `mv -n 1.txt 2.txt` | 目标已存在就不覆盖                     |

  > Tips：`mv`移动目录不需要递归参数；跨文件系统移动时底层其实是复制+删除，大文件会明显变慢。

+ `rm`

  + 删除文件或目录

  | 常见用法          | 效果                                       |
  | ----------------- | ------------------------------------------ |
  | `rm 1.txt`        | 删除文件                                   |
  | `rm 1.txt 2.txt`  | 删除多个文件                               |
  | `rm -r aaa`       | 递归删除目录及其内容                       |
  | `rm -rf aaa`      | 递归**强制**删除，不询问                   |
  | `rm -i 1.txt`     | 删除前询问                                 |
  | `rm *.txt`        | 借助通配符批量删除                         |

  > Tips：Linux的`rm`**没有回收站**，删了就是删了，恢复非常麻烦，所以删之前先用`ls`看一眼要删的东西。
  >
  > `-f`（force）就是强制删除、不再询问，同时会忽略不存在的文件；很多发行版给`rm`默认配了`rm -i`的别名，`-f`把最后一道确认保险也拆了。

#### rm -rf 的危险边界

`rm -rf`不是不能碰，而是要知道它能删到哪。危险主要来自**通配符展开**和**变量为空**这两种情况，而不是命令本身：

| 危险写法                     | 实际发生的事                                                 |
| ---------------------------- | ------------------------------------------------------------ |
| `rm -rf *`                   | 删掉当前目录下所有非隐藏文件，一旦`pwd`错了目录就全没了      |
| `rm -rf *.txt * .txt`        | 多敲一个空格，`*`单独成一个参数，等于删掉整个当前目录        |
| `rm -rf $DIR/`（`DIR`为空）  | 展开成`rm -rf /`，如果再加`--no-preserve-root`就是删库跑路   |
| `rm -rf ./*` 与 `rm -rf .*`  | `.*`会匹配到`.`和`..`，`rm`会拒绝删除`.`和`..`，但同目录下其他隐藏文件照样被删 |
| `rm -rf /`                   | 新版coreutils默认拒绝，但换成`rm -rf /*`、`rm -rf /home/*`依然生效 |

> Tips：`-r`递归、`-f`强制，两个一起用就是目录里所有东西都删、不要问我，一旦参数写错没有任何挽回机会（**没有回收站**）。

规避方法：

1. 删之前先`ls`一遍确认匹配范围，或者用`ls -d 通配符`只列名字；
2. 变量一定要加引号并检查，写成`rm -rf "${DIR:?}/"`，`DIR`为空时直接报错退出；
3. 用`Tab`补全代替手打路径，少一个拼写错误就少一次事故；
4. 重要目录想保险可以装`trash-cli`，用`trash`代替`rm`，东西先进回收站；
5. 实在要删，先`mv`到`/tmp`放几天，确认没用了再删。

### 1.3 绝对路径与相对路径

| 类型     | 写法特点                       | 例子                             |
| -------- | ------------------------------ | -------------------------------- |
| 绝对路径 | 从`/`（根目录）开始写完整路径  | `/home/nikai/Work/a.txt`         |
| 相对路径 | 从当前目录开始算，不以`/`开头  | `Work/a.txt`、`../a.txt`         |

几个特殊的路径符号：

| 符号   | 含义                                   |
| ------ | -------------------------------------- |
| `/`    | 根目录                                 |
| `~`    | 当前用户的家目录                       |
| `.`    | 当前目录                               |
| `..`   | 上一级目录（`../..`就是上两级）        |
| `-`    | 上一次所在的目录（只在`cd`里有意义）   |

> Tips：判断是绝对路径还是相对路径，就看开头有没有`/`。`cd /home`是绝对路径，`cd home`是相对路径。
>
> 目录名写错、或者没有执行权限时，会报`No such file or directory`或`Permission denied`，先`pwd`确认自己在哪，再`ls`看看目标在不在。

### 1.4 通配符

| 通配符       | 含义                                     | 例子                          |
| ------------ | ---------------------------------------- | ----------------------------- |
| `*`          | 匹配任意长度的任意字符（包括0个）        | `ls *.txt` 列出所有txt文件    |
| `?`          | 匹配任意**一个**字符                    | `ls 1?.txt` 匹配`1a.txt`、`12.txt` |
| `[abc]`      | 匹配括号里任意一个字符                   | `ls [ab].txt` 匹配`a.txt`、`b.txt` |
| `[a-z]`      | 匹配一个范围内的字符                     | `ls [0-9].txt` 匹配`1.txt`~`9.txt` |
| `{a,b}`      | 展开成多个参数（花括号展开，bash特性）   | `touch 1.{txt,md}` 生成`1.txt`、`1.md` |

> Tips：`*`不匹配以`.`开头的隐藏文件，想匹配隐藏文件要写成`.*`，而`rm .*`非常危险，因为它会顺带匹配到`.`和`..`。
>
> 通配符是**shell先展开再把结果交给命令**的，所以`rm *.txt`实际执行时已经被替换成了具体的文件名列表，一旦写错一个字符，删掉的东西可能完全不同。想确认会匹配到哪些文件，先`ls *.txt`看一眼。
>
> `{a,b}`属于bash的花括号展开，和`*`机制不同，`[abc]`/`?`才是通配符（glob）；花括号展开也可以嵌套，如`{1..5}.txt`会生成1到5五个文件。

### 1.5 查看文件：cat / less / head / tail

| 命令                     | 适用场景                                   |
| ------------------------ | ------------------------------------------ |
| `cat 1.txt`              | 文件小，直接一口气打印                     |
| `cat -n 1.txt`           | 带行号显示                                 |
| `cat 1.txt 2.txt`        | 按顺序拼接显示多个文件                     |
| `less 1.txt`             | 文件大，分页查看，可以上下翻、搜索         |
| `head 1.txt`             | 只看开头10行                               |
| `head -n 5 1.txt`        | 只看开头5行                                |
| `tail 1.txt`             | 只看结尾10行                               |
| `tail -n 5 1.txt`        | 只看结尾5行                                |
| `tail -f 1.txt`          | 实时跟踪文件新增内容（看日志神器）         |
| `tail -F 1.txt`          | 同`-f`，但文件被重命名/切割后还能继续跟    |

`less`里的常用按键：

| 按键       | 效果                 |
| ---------- | -------------------- |
| `空格`/`f` | 向下翻一页           |
| `b`        | 向上翻一页           |
| `g` / `G`  | 跳到开头/结尾        |
| `/关键字`  | 向下搜索，`n`下一个  |
| `q`        | 退出                 |

> Tips：`cat`对大文件会一直往屏幕上输出，刷完只剩最后几屏，所以超长的文件一律`less`。`cat -A`能把制表符、行尾符显示出来，排查看起来一样但实际不相等的文本很有用。
>
> `tail -f`会一直挂着不退出，按`Ctrl+C`结束；`head`和`tail`也支持`-c`按字节看，如`head -c 100 1.txt`。

### 1.6 搜索与统计：grep / wc

`grep`从文件里筛出包含关键字（或匹配正则）的行：

| 常见用法                          | 效果                                   |
| --------------------------------- | -------------------------------------- |
| `grep "root" /etc/passwd`         | 找包含`root`的行                       |
| `grep -i "root" 1.txt`            | 忽略大小写                             |
| `grep -v "root" 1.txt`            | 反向匹配，输出**不含**关键字的行       |
| `grep -n "root" 1.txt`            | 显示匹配行的行号                       |
| `grep -c "root" 1.txt`            | 只输出匹配的行数                       |
| `grep -l "root" *.txt`            | 只列出包含关键字的文件名               |
| `grep -r "root" /a`               | 递归搜索整个目录                       |
| `grep -w "root" 1.txt`            | 全词匹配，避免`root`匹配到`rootless`   |
| `grep -A 2 "root" 1.txt`          | 显示匹配行及其后2行                    |
| `grep -B 2 "root" 1.txt`          | 显示匹配行及其前2行                    |
| `grep -C 2 "root" 1.txt`          | 前后各2行                              |
| `grep -E "root\|admin" 1.txt`     | 用扩展正则，`\|`表示或运算            |

> Tips：关键字里带空格或特殊符号时要用引号包起来；`grep`默认支持基本正则，想用`|`、`+`、`()`这些语法可以加`-E`。

`wc`统计行数、单词数、字节数：

| 常见用法          | 效果                             |
| ----------------- | -------------------------------- |
| `wc 1.txt`        | 依次输出 行数 单词数 字节数 文件名 |
| `wc -l 1.txt`     | 只统计行数                       |
| `wc -w 1.txt`     | 只统计单词数                     |
| `wc -c 1.txt`     | 只统计字节数                     |
| `wc -m 1.txt`     | 统计字符数（多字节字符用它）     |
| `ls \| wc -l`     | 统计当前目录下有多少项           |

> Tips：`wc -l`统计的是**换行符的个数**，所以最后一行如果没有换行符，结果会比肉眼看到的行数少1。
