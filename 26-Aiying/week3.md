## docker的基本命令

| 目的             | 命令                        |
| ---------------- | --------------------------- |
| 查看版本         | `docker --version`          |
| 查看运行中的容器 | `docker ps`                 |
| 查看所有容器     | `docker ps -a`              |
| 下载镜像         | `docker pull alpine`        |
| 查看本地镜像     | `docker images`             |
| 创建并启动新容器 | `docker run`                |
| 启动已有容器     | `docker start 容器名`       |
| 停止容器         | `docker stop 容器名`        |
| 重启容器         | `docker restart 容器名`     |
| 查看日志         | `docker logs 容器名`        |
| 进入运行中的容器 | `docker exec -it 容器名 sh` |
| 删除已停止容器   | `docker rm 容器名`          |
| 删除镜像         | `docker rmi 镜像名`         |
